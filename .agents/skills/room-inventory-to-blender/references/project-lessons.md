# 室内建模纠错经验

- 用同一张照片可见的墙、窗、门或家具作为方位锚点。只调整有冲突的物件关系。采用负尺度镜像时复核法线、材质方向与局部轴。
- 将凹区包含与实际穿插分开检查。环形家具与其中正常摆放的桌子可能具有相交的世界包围盒。门窗需要检查实体洞口和宿主墙。
- 记录主场景的活动相机及其位置。一个相机列表包含多张预览的工程，仍需检查中央相机是否正确设置。剖切图用独立展示场景；更新照片对照时，渲染和校验应使用同一版几何。
- 比较实拍照片前先核对物体是否在画幅内、是否位于相机前方、是否可见。近似匹配相机时，只核对关系是否相容。
- 路径校验按交付目标采用相应玩家模型，记录形状、高度、宽度和步长。圆形行人与方块玩家的间隙要求不同。
- 区分完整的数字模型和已确认的真实轮廓。推测的门位、层高、隐蔽墙体和区域连接始终记录依据。
