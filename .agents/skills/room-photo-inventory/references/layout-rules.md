# 候选户型补全与常识校验

## 输出语义

缺少实测/完整照片时只能得到候选，不叫真实户型、测绘图或已验证重建。分开写 observed、inferred、assumed；照片里可见的物体身份与它的全局位置可有不同置信度。完整外轮廓、尺度、未拍墙体、门位和卫生间连接通常是假设。保留原 objects.json，不用补全结果回填成观察事实。

生成 layout-candidate.json（区域、坐标、资产、门窗、通行约束、假设列表），floorplan-candidate.png（俯视/轴测效果图），layout-validation.json（逐项PASS/WARN/FAIL/UNKNOWN、检查方法与限制），layout-review.html（可编辑报告）。如使用现有 Blender 项目，复制成候选工程；校验具体数据并渲染同一套几何，避免效果图与校验对象不一致。若用 imagegen 概念图，只能视觉核对，不能声称验证过其精确空间和数量；参考输入看不全时不要导入示例图的厨房/阳台等新功能。

## 可靠性分层

1. 来源约束：同一件物体跨图去重；镜中副本、不同灯光不是新物体。每个观察资产可追溯图片，不在可见证据中虚构电视/床/厨房。
2. 数量：以证据推导数量。一个普通单床卧室常见一床，但双床、亲子、多门、多电视都合理；仅对本次明确配置或已观察数量检查。门区分入户门、内门、无门拱口、窗、镜。
3. 几何：包含在所属区域、落地/承托、避免家具与墙/窗帘实质穿插；包围盒相交只是筛查，C形座台、桌位于凹区、盆与柜体等正常嵌套不能直接判错。布尔开口/环形物体用实际网格或对应形状检查。
4. 可达性：入口到床侧/卫浴/主要活动点连通；门扇摆动与固定家具不冲突；窗或圆形墙洞不得当成可通行门；淋浴门不能封死马桶或洗手盆。用明确玩家宽度和障碍几何做寻路，未做不能写PASS。
5. 尺度建议：普通通道净宽可先以0.60m作狭窄提醒、0.80–0.90m作舒适目标；床侧约0.45–0.60m作设计提醒；门宽/无障碍/疏散须现场和适用标准确认。这些是建模启发，不是法规合规判定。
6. 系统合理性：床不挡入口、显示面与观看区有合理视线、投影机和幕布成对且朝向合理；卫生间常见台盆/马桶/淋浴但允许合理例外；排水/承重/消防/电气不可从照片认证。
7. 不确定性：未拍区域的结构、尺寸、阳台可进入性、给排水及管线留UNKNOWN。缺证据不等于缺实体；规则通过仅表示候选内部一致，不证明真实房源一致。

## 检查呈现

每条记录 id、severity、status、scope、evidence、method、result、limitations。不要把UNKNOWN当PASS；不要给无依据的可靠性百分数。给出哪些补充测量或照片可以推翻/确认方案。可有多个候选，不需要为了“完整好看”强行补入未观察设施。

## 距离驱动候选布局

加载 furniture-distances.json 和各资产尺寸范围共同设置家具体块大小、区域尺度与相对位置，明确参照部位与坐标转换。同向摆放时中心距 = 两件沿连接轴的半尺寸 + 边缘净距；旋转/曲线形状使用实际轮廓，不套此式。尺寸锚点与从该锚点推导的距离共享尺度误差，不能当两份独立证据重复加权。按同一几何回测选用距离是否落在源区间；未知/冲突记录保留，不能放宽源区间来追认既有布局。
